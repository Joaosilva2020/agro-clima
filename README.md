# 🌾 Clima para o Agro M2

Aplicação simples de consulta de clima com React e API OpenWeather.

hospedado em: netlify
para visualizar clique aqui : https://reliable-gecko-9cd3de.netlify.app/

## 📥 Instalação e Execução

### 1. Clonar o repositório
```bash
git clone https://github.com/Joaosilva2020/agro-clima.git
cd agro-clima
```

### 2. Instalar dependências
```bash
npm install
```

### 3. Executar
```bash
npm run dev
```

Abra: **http://localhost:5173**

## 📦 Tecnologias

- React 19.2.0
- Vite
- Tailwind CSS
- Axios
- API OpenWeather

## 🎨 Como Usar

1. Digite o nome de uma cidade
2. Clique em "Buscar"
3. Veja a temperatura e outras informações

## 🌐 API

Usa a API OpenWeather: https://api.openweathermap.org/data/2.5/weather

Retorna:
- Temperatura (°C)
- Sensação térmica (°C)
- Umidade (%)
- Velocidade do vento (m/s)
- Descrição do clima
